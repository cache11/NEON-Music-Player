
# NEON Music Player

NEON Music Player is a Python desktop music player with an AI-powered music genre classification feature.

## Features

- Play and manage music
- Add songs from your computer
- Classify music genres using an AI model
- View genre classification results
- Use a modern desktop interface built with HTML, CSS, JavaScript, Python, and pywebview

## Technologies Used

- Python
- pywebview
- HTML, CSS, and JavaScript
- AI music genre classification
- Joblib model

## Project Structure

- `main.py` - Main application
- `classifier.py` - Music genre classification
- `storage.py` - Music storage functions
- `requirements.txt` - Python dependencies
- `ui/` - User interface files
- `models/genre_model.joblib` - Trained genre classification model

## How to Run

1. Install Python on your Windows computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required packages:

   `pip install -r requirements.txt`

5. Start the application:

   `python main.py`
